Conradi Map

The Conradi Map is a 2-dimensional system with the following equation:

xn+1= sin(xn2 -yn2 +a) yn+1= cos(2xnyn +b)

I first learned about this system from a Facebook post by Professor Simoni Conradi (see references below), but was initially unable to reproduce it. He graciously informed me that that his posted rendition was done via Lagrangian Descriptors, which opened the door to some really interesting other rendering opportunities. Below are both traditional phase portraits as well as Lagrangian descriptor versions.
