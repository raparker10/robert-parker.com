Sprott Attractor

The Sprott attractor is a 3-dimensional attractor produced by the following equation:

xn+1 = xn + ( yn +a xn yn + xn zn) dt yn+1 = yn + ( 1 - b xn2 + yn zn) dt zn+1 = zn + ( xn - xn2 - yn2) dt
