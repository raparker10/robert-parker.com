Mandelbrot Lambda Function Fractal

The Mandelbrot Lambda Function Fractal can be generated with the following equation, which extends the traditional equation by allowing pertubations (a+bi) and (c+di):

Zn+1 = Cfn ( Zn +(a+bi) ) (c+di)

The 'fn' can be replaced by any function, I enjoy using the following trigonometric function: None (evaluated without a function), Sin, Cos, SinH, CosH, ez, Ln, 2z.
