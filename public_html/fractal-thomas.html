Thomas Attractor

The Thomas attractor is a 3-dimensional attractor produced by the following equation:

xn+1 = xn +( sin( yn ) -axn)dt yn+1 = yn +( sin( zn ) -ayn)dt zn+1 = zn +( sin( xn ) -azn)dt
